# ElecKit release packages

This folder is generated by the GitHub Actions release workflow after successful builds for all supported Revit versions.

## Folder layout

\`\`\`text
Release/
├── README.md
├── ElecKit-Installer.exe
└── RevitVersions/
    ├── 2020/  (ElecKit.dll, ElecKit.addin, BUILD-INFO.txt)
    ├── 2021/
    ├── 2022/
    ├── 2023/
    ├── 2024/
    ├── 2025/
    ├── 2026/
    └── 2027/
\`\`\`

The installer registers the version-specific add-in for each Revit version selected during setup. It installs each DLL under the user's Revit Addins directory and places the corresponding manifest in that version's Addins directory.

**Important:** CI build success verifies compilation and package contents; it does not replace smoke-testing inside each installed Revit release. Use only packages produced by the workflow. Do not manually copy one Revit version's DLL into another version's folder.

The binary files are generated outputs and are committed here by the workflow only after all eight version builds and installer compilation succeed.
